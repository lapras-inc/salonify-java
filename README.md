# Salonify

**Salonify はオンラインサロン・プラットフォームです。** 誰でもサロンを開設して会員を募集し、会員は月額プランに加入してコンテンツとコミュニティに参加できます。**Java 21 / Spring Boot** 製、サーバーサイドレンダリングの Web アプリで、コードレビュー実演イベント用のデモとして作られています。

主な機能:

- **サロン開設・運営**: サロン作成・編集、複数の料金プラン（トライアル・初月割引）、公開 / 招待 URL 限定
- **プラン課金・入退会**: プラン選択・変更・退会、請求履歴（**決済はデフォルトでモック**。詳細は後述）
- **会員限定投稿**: Markdown 投稿、画像アップロード、プラン限定公開、下書き、ピン留め、いいね、YouTube 埋め込み
- **掲示板**: スレッド、コメント（1 段ネスト）、いいね、通報、ページネーション
- **運営ダッシュボード**（オーナー）: 売上見込み・会員数、会員管理、招待 URL 管理、売上・振込申請
- **プラットフォーム管理**（管理者）: ユーザー管理（検索・停止・管理者付与）、サロン管理、通報管理

登場ロールは **ゲスト / 会員 / サロンオーナー / プラットフォーム管理者** の 4 種です。

> **このアプリが何であるかを、機能ごとの実装状況（本物 / モック / 未実装）や意図的な「奇妙な仕様」まで含めて詳しく知りたい場合は [`docs/OVERVIEW.md`](docs/OVERVIEW.md) を参照してください。**

## 起動方法（Docker で一発）

必要なもの: Docker のみ（Java/Maven はホストに不要。ビルドはコンテナ内で行います）。

```bash
docker compose up --build
```

- DB（PostgreSQL 16）起動 → スキーマ自動反映 → シードデータ投入 → アプリ起動まで自動で行われます。
- 起動後、http://localhost:8080 にアクセスできます。

停止・データ初期化:

```bash
docker compose down       # 停止（データは保持）
docker compose down -v     # 停止 + DB/アップロードを完全初期化
```

## モック/ローカル実装について

外部サービス（決済・メール・画像ストレージ）にはデフォルトで接続せず、ローカルで完結します。

| 機能 | このアプリでの挙動 |
|------|------|
| **メール送信** | 送信されません。認証コード・リセットコードは**認証画面に直接表示**され、アプリログにも出力されます |
| **決済（入会）** | `STRIPE_SECRET_KEY` 未設定時は Stripe を使わず即入会します。初回分の請求レコードのみ記録されます（実際の課金なし） |
| **振込申請（payout）** | 何も処理されません（成功メッセージのみ）。手数料計算（5%）だけ実装されています |
| **画像アップロード** | クラウドではなくコンテナ内 `/app/uploads`（docker volume）に保存し、`/uploads/**` で配信します |

定期課金バッチは存在しません。入会後の再請求は発生しません。

### 決済（入会）の二段構え

`STRIPE_SECRET_KEY` の有無で入会フローが切り替わります。

- **未設定（デフォルト）**: 上記のとおり、Stripe を使わず即入会します。
- **設定時**: テストキー（`sk_test_...`）を渡して起動すると、入会ボタン押下時に Stripe Checkout（テストモード）へ遷移します。テストカード番号 `4242 4242 4242 4242`（有効期限・CVC は任意の未来日・任意の3桁）で決済すると入会が確定します。Webhook・継続課金・解約時のStripe側同期は対象外です。

```bash
STRIPE_SECRET_KEY=sk_test_... docker compose up --build
```

## 技術スタック

Java 21 / Spring Boot 3.5（Spring MVC + Thymeleaf、サーバーサイドレンダリング）/ Spring Data JPA (Hibernate) /
PostgreSQL 16 / JWT (jjwt) / BCrypt (spring-security-crypto) / commonmark。
認証・認可は Spring Security フィルタチェーンを使わず、JWT Cookie + Interceptor + ガードで自前実装しています。
