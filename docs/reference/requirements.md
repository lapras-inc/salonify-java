# オンラインサロンプラットフォーム 要件定義書

## 1. プロジェクト概要

### サービスコンセプト
誰でもオンラインサロンを開設・運営できるマルチテナント型プラットフォーム。
運営者（オーナー）がサロンを立ち上げ、会員を募集し、月額課金でコンテンツとコミュニティを提供する。

### 類似サービス調査まとめ

| サービス | 手数料 | 特徴 |
|---|---|---|
| DMM オンラインサロン | 10〜20% | 国内最大（4,000サロン/会員100万人）、専用アプリ完結、サポート充実 |
| CAMPFIRE Community | 15〜17% | クラファン母体（会員510万人）、決済多様、ツール選択自由 |
| YOOR | 18%（報酬率82%） | 審査なし即日開設、シンプル設計 |
| Salon.jp | 約20% | エンタメ色強い、Facebook連携 |
| fan.salon | 要問合せ | LINE連携型 |

### 差別化ポイント（目指す方向性）

- 手数料を低く抑える
- 外部ツールに依存せずプラットフォーム内で完結するコミュニティ機能
- 運営者にとってシンプルで即日開設できるUX

## 2. ステークホルダー

| 役割 | 説明 |
|---|---|
| プラットフォーム管理者 | サービス全体の管理（審査・運営監視・手数料設定） |
| サロンオーナー | サロンを開設し会員を募集・コンテンツを提供する |
| 会員（メンバー） | サロンに入会してコンテンツを閲覧・コミュニティに参加する |
| 未登録ユーザー | サロンのランディングページを閲覧し入会を検討する |

## 3. 機能要件

### 3-1. 認証・アカウント管理

- メールアドレス＋パスワードによる新規登録／ログイン
- プロフィール設定（表示名、アイコン画像、自己紹介）
- パスワードリセット
- 退会処理（会員の場合、サブスクリプション解約を伴う）

### 3-2. サロン開設・管理（オーナー向け）

#### サロン作成

- サロン名、キャッチコピー、詳細説明文の入力
- カバー画像・サムネイル画像のアップロード
- カテゴリ選択（ビジネス / 趣味 / アート / テクノロジー / etc.）
- 公開設定（公開 / 非公開 / 招待制）

#### 料金プラン設定

- 月額料金の設定（例: ¥500〜¥100,000）
- 複数プランの設定（ライトプラン／スタンダードプラン／プレミアムプラン）
- 無料お試し期間の設定（0〜30日）
- 初回割引設定

#### サロン管理ダッシュボード

- プランごとの契約者数 × 月額 = 想定月次売上の表示
- 会員一覧（入会日、プラン、決済ステータス：成功 / 失敗）
- 会員のプラン変更・強制退会

### 3-3. 決済・課金

- Stripe を利用したクレジットカード決済（Visa / Mastercard / JCB / Amex）
- 月額サブスクリプション（自動更新）
- 初回課金 → 翌月以降自動引き落とし
- 支払い失敗時のリトライ処理（3回リトライ後に会員資格停止）
- 領収書・請求書の自動発行（PDF）
- 売上の振込申請（月次、最低振込額あり）
- プラットフォーム手数料の自動控除

### 3-4. コンテンツ配信（オーナー → 会員）

#### 投稿機能

- リッチテキストエディタによる記事投稿
- 画像・ファイル添付（PDF、ZIP等）
- 動画埋め込み（YouTube URL）
- 投稿の公開範囲設定（全会員 / 特定プランのみ / 限定公開URL）

#### コンテンツ管理

- 投稿一覧
- 固定ページ（ウェルカムページ等）

### 3-5. コミュニティ機能（BBS / 掲示板）

#### トピック・スレッド

- 会員がトピック（スレッド）を新規作成
- テキスト・画像の投稿
- コメント返信（ネスト1段まで）
- いいね / リアクション機能
- 通報・モデレーション機能


### 3-6. サロン探索・ランディングページ

- サービストップにサロン一覧（カテゴリ・人気順・新着順でフィルタ）
- 各サロンのLP（会員でなくても閲覧可能）
  - サロン紹介文
  - オーナープロフィール
  - 料金プラン
  - 会員数・口コミ（任意）
  - 入会ボタン（CTAボタン）

### 3-7. プラットフォーム管理（管理者向け）

- サロン・ユーザーの停止・削除
- 売上・手数料のレポート
- 規約違反の通報管理

## 4. 非機能要件

### 4-1. セキュリティ
- HTTPS 必須
- パスワードのハッシュ化（bcrypt）
- クレジットカード情報は保持しない（Stripe 管理）
- 会員限定コンテンツのURL直アクセス対策（認証チェック）
- レートリミット（ログイン・投稿）

### 4-2. パフォーマンス
- ページ初期表示 2秒以内（LCP）
- 画像・動画は CDN 配信
- 掲示板は無限スクロール or ページネーション

### 4-3. 可用性
- 稼働率 99.5% 以上
- 定期バックアップ（日次）

### 4-4. スケーラビリティ
- マルチテナント設計（サロンごとにデータ分離）
- サロン数・会員数が増えても性能劣化しない構成

## 5. 画面一覧（ページ構成）

### 未ログイン
- `/` — トップ（サービス説明 + サロン一覧）
- `/salons` — サロン検索・一覧
- `/salons/:id` — サロンLP
- `/login` — ログイン
- `/signup` — 新規登録
- `/salons/:id/join` — 入会フロー（料金確認 → カード入力 → 完了）

### 会員ログイン後
- `/dashboard` — マイページ（参加中のサロン一覧）
- `/salons/:id/home` — サロンホーム（最新投稿、お知らせ）
- `/salons/:id/posts` — コンテンツ一覧
- `/salons/:id/posts/:postId` — コンテンツ詳細
- `/salons/:id/board` — 掲示板トップ（カテゴリ一覧）
- `/salons/:id/board/:categoryId` — スレッド一覧
- `/salons/:id/board/:categoryId/:threadId` — スレッド詳細
- `/account` — アカウント設定
- `/account/billing` — 支払い履歴・カード管理

### オーナーログイン後
- `/owner/salons/new` — サロン作成
- `/owner/salons/:id/edit` — サロン設定
- `/owner/salons/:id/dashboard` — 運営ダッシュボード
- `/owner/salons/:id/posts/new` — コンテンツ投稿
- `/owner/salons/:id/members` — 会員管理
- `/owner/salons/:id/revenue` — 売上・振込

## 9. その他

- プラットフォーム手数料率（競合は10〜20%。Stripeの決済手数料3.6%を含むかどうか）
    - 決済手数料を含み、5%
- サロン開設に審査を設けるか（無審査即日 vs 審査制）
    - 設けない
- 動画直アップロードをどの段階で対応するか（コスト大）
    - 対応しない
- LINE / Discord 連携の要否
    - 対応しない
- スマホアプリ対応の優先度
    - 実装しない
- 不正コンテンツ（アダルト等）のガイドライン設計
    - 考慮しない
